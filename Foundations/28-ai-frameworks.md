# What companies are actually using today (2026)

There isn't a single dominant framework. Different organizations choose based on their needs.

| Area                   | Common choices                                        |
| ---------------------- | ----------------------------------------------------- |
| LLM APIs               | OpenAI, Anthropic, Google Gemini                      |
| Agent Frameworks       | LangGraph, OpenAI Agents SDK, CrewAI, Semantic Kernel |
| Workflow Orchestration | LangGraph, Temporal, custom orchestrators             |
| RAG                    | LangChain, LlamaIndex, custom implementations         |
| Vector DB              | LanceDB, pgvector, Pinecone, Milvus, Weaviate, Qdrant |
| Evaluation             | LangSmith, DeepEval, Ragas, custom evaluation         |
| Deployment             | FastAPI, Docker, Kubernetes, Azure AI, AWS Bedrock    |
