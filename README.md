# ai-engineering-playbook

This repository is a practical playbook for building AI-powered applications with strong engineering fundamentals. It moves from core concepts such as tokens, embeddings, retrieval, and prompting to more advanced topics like memory, state management, tool execution, agents, and evaluation.

## What this book covers

- Foundations of LLMs and AI systems
- Retrieval and ranking techniques such as embeddings, reranking, BM25, and hybrid search
- Prompt construction, context engineering, and memory design
- Tool use, state management, observability, evaluation, and agent architecture
